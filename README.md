📚 Repositório de Estudos de Algoritmos - Iniciante
Este repositório foi criado com o objetivo de reunir e organizar exercícios, exemplos e anotações voltados para o estudo de algoritmos para iniciantes, utilizando principalmente a linguagem C++.

🧠 Objetivos
Praticar a lógica de programação e algoritmos básicos

Desenvolver raciocínio computacional

Aprender a estruturar soluções eficientes para problemas comuns

Servir como base para estudos mais avançados em programação competitiva ou estruturas de dados

🛠️ Conteúdo
📌 Estruturas de controle (if, else, switch)

🔁 Laços de repetição (for, while, do-while)

📦 Vetores e matrizes

🧮 Funções e recursividade

🗃️ Estruturas básicas (structs, enums)

📈 Algoritmos clássicos (busca, ordenação etc.)

🚀 Tecnologias Utilizadas
Linguagem: C++

Compilador: g++

Ferramentas auxiliares: GDB para depuração (quando necessário)

📂 Organização
Os arquivos estão organizados por temas ou níveis de dificuldade. Cada pasta ou arquivo inclui comentários explicativos para facilitar o entendimento do código.

✅ Requisitos
Para compilar e executar os exemplos, você precisará de:

Um compilador C++ instalado (como g++)

(Opcional) GDB para depuração

🤝 Contribuições
Este repositório é voltado para estudos pessoais, mas sugestões e contribuições são bem-vindas!
